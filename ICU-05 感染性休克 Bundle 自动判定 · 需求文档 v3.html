ICU-05 感染性休克 Bundle 自动判定 · 需求文档 v3

一页速览

  • 分母：入院 24h 内进 ICU（入科类型 = 入院 / 手术入院 / 外院）且确诊脓毒性休克
  • T0：入科后 VI_ICU_ZYYZ 第一条医嘱 orderTime
  • 判定：全自动计算 + 三层人工覆盖（病例 / 判定项 / SOFA 分项）
  • 感染部位：人工选择，落库持久化，不阻塞分母
  • 去甲肾上腺素：按碱基计，换算系数 1.0，不除 2（主任定）
  • SOFA / SOFA-2：双版本并行，仅辅助展示，永不作为任何指标分子分母

本文档替换 v2 的 §4 §5 §12 §13，新增「感染部位入库」与「三层人工覆盖」。v2 的 §1 §2 §3 §8 §9 §10 §11 原样有效。

第 12 条修法：

def _pao2_fio2_score(pao2, fio2, has_advanced_support):
    ratio = pao2 / fio2 if fio2 > 0 else 0
    if ratio >= 400:   return 0
    elif ratio >= 300: return 1
    elif ratio >= 200: return 2
    elif ratio >= 100: return 3 if has_advanced_support else 2
    else:              return 4 if has_advanced_support else 2

7.4 去甲肾上腺素剂量 · 唯一换算点

NE_LABEL_BASIS = "base"（主任定：按去甲肾上腺素碱基计），换算系数 1.0，不除 2。

_LIQUID_UNITS = {"ml", "mL", "毫升"}
_DOSE_UNITS   = {"mg", "毫克"}
WEIGHT_MIN_KG, WEIGHT_MAX_KG = 20.0, 300.0
NE_LABEL_BASIS = "base"
_LABEL_TO_BASE = {"base": 1.0, "salt": 0.5}

def ne_ugkgmin(action, weight_kg):
    dq = []
    if NE_LABEL_BASIS not in _LABEL_TO_BASE:
        return None, ["NE_LABEL_BASIS 未配置，拒绝计算"]
    if (action.get("doseUnit") or "").strip() not in _DOSE_UNITS:
        return None, ["dose 单位不在白名单"]
    if (action.get("liquidUnit") or "").strip() not in _LIQUID_UNITS:
        return None, ["liquidAmount 单位不在白名单"]
    liquid_ml = float(action.get("liquidAmount") or 0)
    if liquid_ml <= 0:
        return None, ["liquidAmount 为 0 或缺失，无法算浓度"]
    if not (WEIGHT_MIN_KG <= (weight_kg or 0) <= WEIGHT_MAX_KG):
        return None, ["体重超出 20 至 300 kg"]
    conc_ug_ml = float(action["dose"]) / liquid_ml * 1000.0
    val = conc_ug_ml * float(action["speed"]) / 60.0 / weight_kg * _LABEL_TO_BASE[NE_LABEL_BASIS]
    if val > 2.0:
        dq.append("NE 剂量异常高，需人工复核")
    return val, dq

speed 单位已确认为 ml/h，浓度必须逐医嘱从 dose / liquidAmount 计算，禁止硬编码常数。构造 MedicationAdministration 时 salt_form 固定传枚举成员 NorepinephrineSaltForm.BASE，永不改。

体重回填：优先 patient 表，其次该病人最近一条合法体重，打 weight_backfilled 标记。

7.5 内核铁律（照搬，不得放宽）

#铁律
1评分是纯函数，相同输入必得相同输出
2内核不访问数据库，只接收已构建好的 observation 集合
3内核不调用 now()，evaluation_time 必须由调用方显式传入
4严禁使用 observed_at 晚于 evaluation_time 的数据
5时间窗左开右闭 (evaluation_time - lookback, evaluation_time]
6所有 datetime 必须 timezone-aware
7每分项输出取值、单位、来源记录 ID、观测时间、缺失状态
8每个评分独立 rulepack + 独立版本号 + content_hash

7.6 展示约束（硬性）

  • 两个 rulepack 恒为 clinical_approval_status = not_approved、lifecycle_status = experimental
  • SOFA / SOFA-2 只能辅助展示与影子比对，不得作为任何质控指标分子分母的判定依据
  • 详情页必须显示：评分版本号、rulepack 版本、result_status、completeness、缺失分项清单、「实验性」标识
  • insufficient 的评分不得触发任何临床提示
  • HFNC 病人两版本呼吸分不同，属预期差异，详情页固定说明，影子比对归因预先列入「算法版本不同」，不进异常清单
